# Origami Puzzle MVP 设计文档

## 范围

基于产品设计文档实现可玩 Demo，验证核心折叠机制。

## 核心功能

- **网格系统**：4×4 网格，每格有正面颜色和背面颜色
- **折叠机制**：沿网格线横折/竖折，被折叠部分背面覆盖到镜像位置，源格变空
- **折叠动画**：方案A（纯2D），折叠区域 scale 从1→0，目标区域淡入新颜色
- **撤销/重置**：状态快照栈，支持逐步撤销和完全重置
- **关卡系统**：8 个预设关卡（附录A），JSON 格式存储
- **胜利判定**：当前可见面与目标图案完全匹配即通关
- **UI**：选关界面、游戏 HUD（折叠次数、撤销/重置按钮）、通关弹窗

## 视觉风格

- 背景：暖白 #F5F0E8
- 文字：棕色 #5C4033
- 强调色：珊瑚红 #E8785A、薄荷绿 #6ABEAB、琥珀黄 #E8B84A
- 圆角卡片、柔和阴影

## 技术方案

- Godot 4.6 + GDScript
- 纯 2D 实现
- 关卡数据用 JSON 文件
- 场景结构：Main → LevelSelect / GameScene
