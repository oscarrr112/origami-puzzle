# 100 关卡设计规范

## 概述

为折纸益智游戏设计 100 个关卡，从入门到终极挑战，形成完整的难度曲线。采用分层策略：~20 关手工设计（教学关 + boss 关），~80 关由生成器批量生成并经质量评估筛选。

## 设计决策

- **对角折叠比重**：~20-25%（约 20-25 关），从第 4 章开始引入
- **网格尺寸**：4×4 为主，第 8 章起引入 5×5
- **最大折叠次数**：最高 6 次（仅最终章最后几关）
- **难度曲线**：波浪式——整体递增，每章开头是休息关，章内由易到难
- **颜色**：前 6 章用 1-3 色（珊瑚红、薄荷绿、琥珀黄），第 7 章起扩充到 4-5 色
- **生成方式**：手工设计关键节点 + 生成器批量填充 + 质量评估筛选

### 每章内部结构

- **第 1 关（休息/教学关）**：手工设计。引入该章新机制，难度低于前一章结尾。
- **第 2-9 关（填充关）**：生成器产出，经质量评估筛选，难度逐步递增。
- **第 10 关（boss 关）**：手工设计。该章最高难度，需要综合运用本章所有机制。

### 对角折叠分布

- 第 1-3 章（关卡 1-30）：纯 V/H，不含对角
- 第 4 章（关卡 31-40）：引入对角折叠，约 3-4 关含对角（纯对角或 V/H + 对角混合）
- 第 5-6 章（关卡 41-60）：每章约 4-5 关含对角
- 第 7-10 章（关卡 61-100）：每章约 3-4 关含对角
- 总计约 20-25 关涉及对角折叠

## 关卡质量评估系统

### 必要条件（不过则淘汰）

1. **可解性**：至少存在一个解法
2. **最优性**：不能用更少折叠次数达成目标（强制用满 max_folds）
3. **少解性**：解法数量 ≤ 3，避免"随便折都能过"

### 趣味性评分（0-100 分，阈值 ≥ 60 入选）

**视觉变化度（0-30 分）**：
- 目标与初始状态的差异格数占比（变化越多越好）
- 目标图案的对称性/规律性加分（有规律的图案更美观）
- 惩罚：目标几乎全空或全满

**解题复杂度（0-40 分）**：
- 折叠顺序是否影响结果（有序依赖 > 无序可交换）
- 是否涉及正面→背面转移（"看不见的一面"思考加分）
- 是否使用不同类型的折叠组合（V+H 或 V+对角 > 纯 V+V）
- 惩罚：所有折叠都沿同一条线

**非显而易见性（0-30 分）**：
- 解法第一步是否"反直觉"（折叠后离目标更远而非更近）
- 贪心策略能否求解（贪心失败 = 高分）

### 生成流水线

```
每章: 生成 500+ 候选 → 可解性过滤 → 最优性过滤 → 少解过滤 → 趣味性评分 → 排序 → 取 top 8 填充
```

## 实现要点

### 生成器扩展

1. **支持对角折叠生成**：生成器需要能随机选择可用折线（包括 V/H/对角），为关卡分配 `folds` 字段
2. **支持 5×5 网格**：验证器和求解器已支持任意尺寸
3. **支持 4-5 色**：扩展颜色参数范围
4. **质量评估模块**：实现趣味性评分函数，集成到生成流水线
5. **批量生成命令**：`python3 level_generator.py generate-100` 一键生成全部 100 关

### 游戏代码修改

1. **COLOR_MAP 扩展**：新增颜色 4（薰衣草紫）和 5（天空蓝）
2. **levels.json 替换**：用生成的 100 关数据替换现有 26 关

### 输出格式

每关 JSON 结构不变：
```json
{
  "id": 1,
  "name": "关卡名",
  "size": 4,
  "max_folds": 1,
  "front": [[...]],
  "back": [[...]],
  "target": [[...]],
  "folds": [{"type": "v", "pos": 2}]
}
```

第 1-3 章的纯 V/H 关卡可省略 `folds` 字段（向后兼容，自动生成所有 V+H 折线）。第 4 章起所有关卡必须显式指定 `folds`。
